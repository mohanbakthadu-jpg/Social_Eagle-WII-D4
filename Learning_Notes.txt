This is a very good intermediate-level RAG assignment because it combines:

Multi-document ingestion
Multiple file formats (PDF, TXT, CSV)
FAISS Vector DB
HuggingFace Embeddings
OpenAI LLM
Source Attribution
LangSmith Monitoring
Streamlit UI

Ingestion
PyPDFLoader
TextLoader
CSVLoader

    chunk_overlap=50
)

sentence-transformers/all-MiniLM-L6-v2

Vector Store
FAISS (Python Inclined)

Retriever
search_kwargs={"k":3}

LLM

Monitoring
